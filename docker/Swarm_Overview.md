# Обзор Docker Swarm (Swarm Overview)

Документ описывает архитектуру кластеров Docker Swarm с разделением на две параллельные среды:

- **Пользователь c (CI):**  
  Узлы этого кластера объединены в рамках одной подсети с маской **/8**. Например, для тестовой среды используется подсеть с префиксом, отличным от продакшн (например, условно `fc00::/8`).

- **Пользователь d (CD):**  
  Узлы этого кластера работают в другой подсети с маской **/8** (например, условно `fd00::/8`). При необходимости можно перейти к маске **/16**, если этого требует масштабируемость или другие соображения.

Общая архитектура предусматривает, что оба кластера входят в единую сеть, объединённую общей маской (например, /7 на уровне сети), а на уровне кластеров производится разделение по подсетям для каждого пользователя.
