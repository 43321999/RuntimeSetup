# Обзор сети и адресного плана

Эта инструкция описывает структуру сети и принципы адресации для узлов.

## IPv6 Адресация

- **Общая сеть:**  
  Все узлы находятся в рамках общей IPv6 подсети с 16-битной маской (например, `fd00::/16`).

- **Выделенные подсети:**  
  Каждый узел получает уникальную подсеть `/64`:
  - Например, узел `aa` может иметь `fdaa::/64` (для продакшн) или `fcaa::/64` (для тестовой среды).

- **Контейнеры:**  
  Адреса контейнеров формируются внутри подсети узла, например:  
  `fdaa::1`, `fdaa::2` или `fcaa::1`, `fcaa::2`.

## IPv4 Адресация

Применяется упрощённая схема:
- **Мастер-узлы:**  
  Пример: `10.11` для узла **aa**, `10.22` для узла **bb** и т.д.
- **Воркер-узлы:**  
  Пример: `10.12` для узла **ab**, `10.13` для узла **ac** и т.д.

## Принципы проектирования

1. **Соответствие адресов именам узлов:**  
   Адреса узлов совпадают с их именами для удобства управления.
2. **Логическая связанность:**  
   Каждый узел получает выделенную подсеть `/64`, а параллельные кластеры объединены в общую подсеть с 16-битной маской.
3. **Упрощённая IPv4 адресация:**  
   Сокращённая запись адресов упрощает ручной ввод и администрирование.
